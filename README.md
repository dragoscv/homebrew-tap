# dragoscv/homebrew-tap

Homebrew formulae for [AXIOM](https://github.com/dragoscv/axiom), the transactional write gate
for coding agents.

```sh
brew install dragoscv/tap/axiom
axiom --version
```

`axiom` is the standalone binary (Node single executable, no Node needed) attached to each
[AXIOM GitHub release](https://github.com/dragoscv/axiom/releases). Checksums come from that
release's `SHA256SUMS`, which is covered by a Sigstore build-provenance attestation:

```sh
gh attestation verify "$(brew --prefix)/bin/axiom" --owner dragoscv
```

`Formula/axiom.rb` is generated by `scripts/render-homebrew-formula.mjs` in the AXIOM repo and
updated by its `release.yml` on every `v*` tag. Do not edit it by hand.
